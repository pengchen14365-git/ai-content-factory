## 📋 待创作选题清单

自动列出所有待创作的选题，按优先级从高到低排序。

```dataview
TABLE WITHOUT ID
  file.link AS "选题标题",
  选题类型 AS "类型",
  创作优先级 AS "优先级",
  创建日期 AS "创建日期"
FROM "01-选题库"
WHERE 选题状态 = "待创作"
SORT 创作优先级 DESC, 创建日期 ASC
```

> **效果说明：** 自动扫描「01-选题库」下所有笔记的 YAML 字段，筛选出「选题状态」为"待创作"的笔记，以表格形式展示标题（可点击跳转）、类型、优先级和创建日期。在选题库中新增或修改选题状态后，表格会自动更新。

## ✍️ 稿件创作进度

自动列出所有创作中的稿件及其文件夹路径。

```dataview
TABLE WITHOUT ID
  file.link AS "稿件文件",
  file.folder AS "所在文件夹"
FROM "02-稿件库/01-创作中稿件"
SORT file.ctime DESC
```

> **效果说明：** 自动扫描「02-稿件库/01-创作中稿件」下的所有文件，快速了解当前有哪些稿件正在创作中。

## 📊 知识库数据总览

```dataviewjs
// 选题库统计
const allTopics = dv.pages('"01-选题库"');
const pending = allTopics.where(t => t.选题状态 === "待创作").length;
const creating = allTopics.where(t => t.选题状态 === "创作中").length;
const completed = allTopics.where(t => t.选题状态 === "已完成").length;
const total = allTopics.length;

dv.table(
  ["指标", "数量"],
  [
    ["📌 总选题数", total],
    ["⏳ 待创作", pending],
    ["✍️ 创作中", creating],
    ["✅ 已完成", completed]
  ]
);
```

> **说明：** 实时统计选题库中各类状态的选题数量，一目了然掌握内容生产进度。
