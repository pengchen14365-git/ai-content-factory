# Prompt 框架说明：如何自定义调试

这个 Prompt 采用 **「角色 → 任务 → 标准 → 输出 → 红线」五段式结构**，你可以对照修改每一段来适配不同场景。

---

## 五段结构拆解

### 1️⃣ 角色定位
> 你是谁？有什么能力？

这是 Prompt 的"人设"段，决定了 AI 以什么视角思考。

**可调参数：**
- 专家身份：选题策划专家 / 行业分析师 / 用户研究员 / 内容策略师
- 能力描述：擅长的具体技能，越具体越好

**示例替换：**
```
你是我的专属行业分析师，擅长从海量信息中提取趋势信号...
```

---

### 2️⃣ 核心任务
> 你要做什么？

一句话说清本次任务目标。不能模糊。

**可调参数：**
- 任务动词：筛选 / 分析 / 提炼 / 对比 / 评估
- 输出形态：选题笔记 / 分析报告 / 对比表格 / 行动清单

**示例替换：**
```
基于行业报告，完成竞品内容策略分析，输出对比分析报告...
```

---

### 3️⃣ 筛选/评估标准（核心）
> 什么要？什么不要？

这是决定输出质量的关键段。标准越清晰，AI 的过滤越精准。

**可调参数：**
- 标准的数量：3-7 条为宜
- 每条标准用「一句话概括 + 解释」的结构
- 可以加否定标准（什么情况下直接过滤）

**示例替换（用于素材筛选）：**
```
1. 高信噪比：信息密度高，不包含废话和注水内容
2. 有数据支撑：观点有数据或案例佐证，非主观臆断
3. 时效性：发布时间在 3 个月内
```

---

### 4️⃣ 输出要求
> 按什么格式输出？

不指定格式，AI 会自由发挥，结果很难复用。这里要**精确到字段级别**。

**可调参数：**
- 输出数量：不少于 X 个
- 每个条目包含的字段：标题 / 描述 / 评估 / 建议 / 优先级
- 分类存储规则：什么内容存到什么位置

**示例替换（用于竞品分析）：**
```
输出不少于 3 个竞品分析条目，每个包含：竞品名称、核心策略、优势、劣势、对我方的启发。
```

---

### 5️⃣ 禁止要求（红线）
> 绝对不能做什么？

这是"负向约束"，防止 AI 跑偏或偷懒。

**可调参数：**
- 禁止内容类型：泛泛而谈 / 同质化 / 无数据支撑
- 禁止行为：脱离素材 / 编造信息 / 跳过步骤

**示例替换：**
```
禁止使用"首先、其次、最后"等结构化套话；禁止生成没有案例支撑的纯理论分析。
```

---

## 快速调试 Checklist

当你发现输出不满意时，按这个顺序排查：

- [ ] 角色是否够具体？（"专家"太宽泛，"新媒体战略顾问"更好）
- [ ] 标准是否有优先级？（5 条标准里哪条最重要？放在第一条）
- [ ] 输出格式是否明确？（说了"表格"还是"列表"？字段有哪些？）
- [ ] 红线是否足够？（AI 正在生成的垃圾内容，你有没有提前禁止？）

---

## 这个 Prompt 可复用的场景

| 场景 | 改什么 | 不改什么 |
|------|--------|---------|
| 素材筛选 | 标准段（3.筛选标准）→ 改为素材质量维度 | 五段结构、输出格式逻辑 |
| 竞品分析 | 角色段（1.专家身份）+ 输出段（4.字段） | 标准段、禁止段 |
| 内容审校 | 任务段（2.目标）+ 标准段（3.评估维度） | 角色段、红线段 |
| 数据分析 | 角色段 + 输出段格式（表格） | 核心是标准段 |
